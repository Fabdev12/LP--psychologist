# Landing page — Psicólogo

Projeto inicial de landing page para um psicólogo, desenvolvido com React, TypeScript, Vite e Tailwind CSS.

## Requisitos
- Node.js versão LTS
- npm

## Executar localmente
```bash
npm install
npm run dev
```

## Gerar build
```bash
npm run build
```

## Estrutura
```text
src/
├── components/
│   ├── layout/ (Header e Footer)
│   └── ui/ (Button, Container e SectionHeading)
├── sections/
│   ├── Hero/
│   ├── Expectations/
│   ├── Approach/
│   ├── About/
│   └── Location/
├── styles/globals.css
├── App.tsx
└── main.tsx
```
